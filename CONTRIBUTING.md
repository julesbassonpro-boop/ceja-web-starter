# Contributing to CEJA Web Starter

Thanks for considering a contribution.

## Good first contributions

- Accessibility improvements
- Better documentation
- Small reusable sections or patterns
- Performance improvements
- Cross-browser fixes
- Deployment examples

## Development

```bash
npm install
npm run dev
```

Before opening a pull request, please make sure the production build succeeds:

```bash
npm run build
```

## Pull requests

Keep changes focused and explain:

1. What problem the change solves
2. What you changed
3. How you tested it

Please avoid adding large dependencies unless they clearly improve the project for most users.

## Accessibility

New UI should remain keyboard usable, preserve visible focus states and use semantic HTML whenever possible.

## Code of conduct

Be respectful, constructive and patient with contributors of all experience levels.
